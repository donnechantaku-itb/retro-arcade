# Retro Arcade

Klassieke DOS-spellen die door hun makers vrij zijn gegeven, speelbaar in de browser.
Classic DOS games released for free by their makers, playable in the browser.

- Emulator: [js-dos](https://github.com/caiiiycuk/js-dos) 8.5.3, GPL-2.0 (in `vendor/js-dos/`), based on DOSBox (GPL-2.0).
- Games are listed in `games.json`; each entry states its licence.
